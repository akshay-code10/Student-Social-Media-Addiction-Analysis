# 📊 Student Social Media Addiction Analysis

An end-to-end Power BI project that explores student social media behavior using interactive dashboards, DAX, Power Query, and data modeling to uncover meaningful insights for academic advisors, counselors, and researchers.

---

## 📌 Project Overview

This project analyzes student demographics, social media usage, sleep patterns, mental health, academic performance, and relationship dynamics. The dashboard enables users to explore trends through interactive visualizations, slicers, bookmarks, and drill-through reports, supporting data-driven decision making.

---

## ❓ Problem Statement

Educational institutions often lack visibility into how excessive social media usage influences students' well-being and academic success. This project provides an analytical dashboard that helps identify behavioral patterns, monitor addiction levels, and support informed interventions.

---

## 🎯 Objectives

- Analyze student social media usage patterns
- Measure the relationship between social media addiction and mental health
- Evaluate the impact of social media on academic performance
- Analyze sleep habits across different age groups
- Explore relationship conflicts associated with social media usage
- Build an interactive dashboard for data-driven decision making

---

## ⚙️ Project Workflow

### 1. Data Preparation

- Loaded Student Details and Platform Details datasets
- Cleaned and transformed data using Power Query
- Validated data types and relationships

### 2. Data Modeling

- Built a Star Schema data model
- Created relationships using Student_ID
- Added a Calendar Table for future time intelligence analysis

### 3. DAX Development

Created calculated columns and measures including:

- Average Usage Hours
- Average Sleep Hours
- Addicted Student Count
- Percentage Academically Affected
- Health Band
- Conflict Level
- Monthly Trend (YTD)

### 4. Dashboard Development

Designed six interactive report pages featuring:

- KPI Cards
- Bar Charts
- Line Charts
- Scatter Charts
- Matrix
- Pie & Donut Charts
- Drill-through Reports
- Bookmarks
- Interactive Navigation

## 📊 Key Insights

- Total students analyzed: **705**
- Average daily social media usage: **4.92 hours**
- Average sleep duration: **6.87 hours**
- Approximately **64%** of students reported that social media affects their academic performance.
- Undergraduate students recorded the highest overall addiction score.
- Facebook was the most frequently used social media platform.
- Higher addiction scores were generally associated with lower mental health scores.
